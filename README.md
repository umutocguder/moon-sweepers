A 3D lunar surface restoration, cleaning simulation, and automation tycoon game. As an astronaut deployed by the Lunar Surface Department, restore the lunar regolith starting with humble cleaning tools, harvest extraterrestrial minerals, sell regolith at the Base Hopper for Lunar Credits, and construct automated rover factories and drone swarms.

---

## 🎮 Gameplay Overview

- **The Premise**: Due to deep budget cuts, you land on the Moon equipped with only a **standard toothbrush**. Scrub dust, gather raw regolith, and build an automated cleaning empire.
- **Core Loop**: Scrub Surface Regolith ➔ Collect Valuable Lunar Minerals ➔ Deposit at Central Hopper ➔ Earn Lunar Credits (LC) ➔ Purchase Industrial Suction Tools, Jetpacks & Automated Autonomous Drones.
- **Lunar Gravity Simulation**: Low gravity physics ($g = -1.62\text{ m/s}^2$) with momentum drifting, high jumps, and vertical jetpack gliding.

---

## 🛠️ Tool Progression

1. **Tier 1 — Standard Toothbrush**: Precise manual scrubbing (1.0 kg/hit).
2. **Tier 2 — Lunar Hand Broom**: Wide sweep arc covering clustered surface dust (3.5 kg/hit).
3. **Tier 3 — Cyclone Vacuum Mk-I**: High-flow suction beam pulling regolith from distance (12 kg/sec).
4. **Tier 4 — Electromagnetic Sweeper**: Radial attraction field collecting metallic debris (30 kg/sec).
5. **Tier 5 — Lunar Sweeper Buggy**: Industrial rover intake collecting massive mineral deposits (100 kg/sec).

---

## 🤖 Automation & Tycoon Systems

- **Central Hopper Base**: Automated refining facility converting collected dust into investable currency.
- **Autonomous Drone Fleet**: Deploy robotic cleaner drones that patrol designated lunar sectors and beam minerals back to base.
- **Conveyor Networks**: Route high-density asteroid impact zones directly into automated processing silos.

## 🚀 Running Locally

### Prerequisites

- Modern Web Browser (Chrome, Safari, Firefox, Edge)
- [Node.js 18+](https://nodejs.org/)

### Quickstart

```bash
# Clone the repository
git clone https://github.com/umutocguder/moon-sweepers.git
cd moon-sweepers

# Install development dependencies
npm install

# Run automated game logic tests
npm test

# Launch local game server
npm start
```

Visit [http://localhost:3000](http://localhost:3000) to start sweeping the Moon.
